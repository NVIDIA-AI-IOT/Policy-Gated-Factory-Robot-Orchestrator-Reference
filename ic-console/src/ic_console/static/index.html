What you're looking at

Live GPU utilization, GPU memory, and system RAM for the entire orchestration, attributed to shared GR00T servers, loaded specialist policies, GR00T relays, VLM servers, OpenClaw, Isaac Sim, and everything else. Samples arrive every 5s from the read-only exporter (ops/ic_gpu_exporter.py). Thor has one unified CPU/GPU memory pool: its colored process bands are RSS allocation, not per-process GPU utilization, and the whole-pool RAM figure is authoritative.

Reading it

The stacked bands show which model is taking how much memory against the card's total. The utilization strip below is whole-GPU compute. Hover either chart for exact values at a timestamp; the table shows the latest sample. "Other" folds training jobs, the router, and cert servers.
